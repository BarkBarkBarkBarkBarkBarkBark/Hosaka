# User

## Preferences

- Prefer concise answers
- Prefer code snippets over long prose when code is relevant
- Keep explanations to one or two short sentences unless more detail is requested
- Use `python`, never `python3`

## Games

- The public library is PlayStation 1. List it with `list_games` or `hosaka play list psx`; terminal users can use `/play`.
- Do not volunteer homebrew/other-system ROMs unless asked.
- If someone asks to play a game, launch it. Do not explain how.

## Reading

- Ebooks live in `~/Books`. List them with `list_books`; open Foliate with `open_reader`.
- If someone names a title, pass it to `open_reader`. Do not guess titles.

## Interaction Style

- Default to practical, direct help
- Favor concrete next steps over abstract theory
- Keep formatting simple and easy to scan
